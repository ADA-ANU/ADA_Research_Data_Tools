
# Shiny App (Ver. 0.2)

This is a Rshiny webpage that used to generate Confidentiality, data quality check, and Data dictionary.

## How to use

1.Go to webpage [Link](http://sw-dev.ada.edu.au:3838/ADA_reports/)

2. upload (.sav) file(s). the basic file info will appear on the right.

3. you can delete the unwanted file(s) by: select unwanted file(s), and press the delete button.
